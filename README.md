**Автор:** Морозов Кирилл Вадимович

Проект отвечает на тестовые вопросы по учебнику В. В. Горяйнова и Е. С. Половинкина «Лекции по ТФКП» (2025). Ответ содержит выбранные варианты, краткое обоснование и ссылки на исходные страницы PDF (`p_XXXX`). Если источника недостаточно, система должна отказаться от ответа.

## Запуск в Google Colab

Клонируйте репозиторий, перейдите в его каталог, включите GPU runtime и выполните:

```bash
!git clone https://github.com/kirillmor/tfkp-evidence-rag.git
%cd tfkp-evidence-rag
!bash scripts/colab_run.sh
```

Скрипт устанавливает зависимости, скачивает учебник и модель, строит корпус и индекс, запускает Qwen3.5-4B через vLLM, выполняет предсказание и эксперименты. Если PDF не скачивается автоматически, загрузите тот же файл из задания и укажите его путь:

```bash
!PDF_PATH=/content/tfkp_2025.pdf bash scripts/colab_run.sh
```

## Как устроена система

- Каждая физическая страница PDF становится отдельным блоком с устойчивым ID `p_XXXX`.
- Поиск объединяет BM25 по словам и символьный TF-IDF по 3–5-граммам (веса 0.65 и 0.35).
- Для итогового режима запрос включает вопрос и варианты ответа; три лучших страницы расширяются соседними.
- Qwen3.5-4B формирует структурированный ответ с обоснованием и цитатами только из найденного контекста.

## Результаты

Открытый набор: 15 вопросов. Метрики ниже взяты из `experiments.csv`; стоимость — средняя вычислительная стоимость по формуле задания.

| Конфигурация | Точность | Q | Средняя стоимость |
| --- | ---: | ---: | ---: |
| Без контекста | 40.00% | — | 1 114.07 |
| Один BM25 RAG | 60.00% | 0.5483 | 4 985.87 |
| Итоговая система | 53.33% | 0.5117 | 4 935.87 |
| Без char TF-IDF | 60.00% | **0.5617** | **4 775.93** |
| Без вариантов в запросе | 60.00% | 0.5083 | 5 922.80 |

Лучшую оценку Q показала абляция без символьного TF-IDF. Текущая итоговая конфигурация не превзошла простой BM25 RAG по Q; удаление вариантов из поискового запроса также ухудшило Q и увеличило стоимость.

## Основные файлы

`build_index.py` и `predict.py` — точки входа; `tfkp_rag/` — реализация; `scripts/` — подготовка данных и эксперименты; `tests/` — тесты. Результаты открытого прогона находятся в `dev_answers.jsonl` и `dev_trace.jsonl`, таблица экспериментов — в `experiments.csv`.
