# Отчёт: доказательный RAG по ТФКП

**Автор:** `ФИО`, **группа:** `ГРУППА`.

## Система

Корпус строится из единственного разрешённого PDF. Каждый физический лист
становится исходным блоком `p_XXXX`; это сохраняет однозначную связь ссылок с
номером страницы PDF. Текст извлекается PyMuPDF, переносы нормализуются, а
последний заголовок раздела `§` записывается в поле `section`.

Индекс не использует генеративных моделей: BM25 работает по нормализованным
словам, символьный TF-IDF — по 3–5-граммам. Их ранги объединяются с весами
0.65 и 0.35. Для итогового режима запрос включает вопрос и все варианты;
берутся три лучшие страницы и их соседи. Контекст предварительно ограничен
18 000 символами и дополнительно обрезается перед запросом по безопасной
верхней оценке токенов.

Qwen3.5-4B получает только этот контекст и возвращает JSON с вариантами,
обоснованием и не более четырьмя ID фрагментов. Отказ обязателен, когда
источник не задаёт единственный ответ. Код проверяет формат, принадлежность
цитат контексту, лимиты и usage endpoint; при испорченном JSON допустима одна
повторная попытка.
